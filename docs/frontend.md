# 前端设计需求

## 前端框架

1. 同时支持nicegui>=3.16.0 、textual >= 8.2.8 、 flet 0.86.5前端设计，基于不同的指令启动不同前端
2. 可以基于上述几种前端框架独立打包，互不干扰
3. 前端框架通过core层与最下面的modules独立功能层后端通信，前端框架尽量采用响应式实现
4. 前端设计要组件模块化，提高复用率
5. 前端设计框架支持语言切换、主题切换、用户切换、配置保存，简洁清晰现代

## nicegui、flet实现的前端页面要求

1. 前端页面布局要求简洁、切换顺畅，所有组件卡片化(大、中、小三种样式)
2. 主页面整体分成常驻区(放置小卡片(小卡片只有图标))、普通区(放置大卡片(大卡片有图标、title、描述、小按钮等组件))、轮转区(放置中卡片(中卡片暂定只有图标、title))
3. 点进去卡片后切换的功能页面是每个模块不同的功能布局和实现，这个跟业务相关后续可调整，这是内容区部分，其中常驻区是悬停在页面的上方，下方有轮转区，用于轮转普通区的模块(类似转盘(也有隐藏式横条可以推拉轮转))
4. 普通区和常驻区的卡片可以拉扯更换，类似手机应用。并且常驻区的小卡片也可以点击切换到功能页面
5. 到功能页面之后有一个可以自由挪动的返回按钮
